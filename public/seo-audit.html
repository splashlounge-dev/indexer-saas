What these checks actually mean

Title & meta description length

Titles roughly 30–60 characters and descriptions roughly 70–160 characters are the least likely to get truncated in Google's search results — that's the range this tool flags.

Heading structure

A single, clear H1 followed by H2s for sections helps both users and search engines understand the page's structure. Missing or duplicate H1s make that structure ambiguous.

Image alt text

Alt text lets screen readers describe images to visually impaired users and gives search engines context for image search — missing alt text is both an accessibility and SEO gap.

Canonical & viewport tags

A canonical tag tells search engines which URL is the authoritative version of a page. A viewport meta tag is required for a page to render correctly on mobile devices, which affects mobile search rankings.
