What this actually does (read before you rely on it)
This calls Google's own PageSpeed Insights API for each URL. When Google has enough real-world Chrome traffic for a page, it returns field data — actual measured experience from real visitors (the CrUX dataset), which is what Google's ranking systems use. If field data isn't available (usually for lower-traffic pages), the results fall back to lab data — a single simulated Lighthouse run, which is a reasonable proxy but not the same as real-world usage. INP in particular requires real interaction data, so it will show as unavailable rather than being estimated when field data doesn't exist. Each metric is rated Good / Needs Improvement / Poor using Google's own published thresholds.

LCP — loading speed

Measures how long it takes the largest visible element (usually a hero image or heading) to render. Slow LCP is most often caused by slow servers, render-blocking CSS/JS, or unoptimized images.

INP — responsiveness

Measures the delay between a user's click/tap and the page visually responding. High INP usually points to heavy JavaScript execution blocking the main thread.

CLS — visual stability

Measures unexpected layout shifts, like text jumping when an ad or image loads without a reserved size. Almost always fixed by setting explicit width/height on images and embeds.

Frequently asked questions

What are Core Web Vitals?

Core Web Vitals are three metrics Google uses to measure real-world page experience: LCP (how fast the main content loads), INP (how quickly the page responds to user interaction), and CLS (how much the layout visually shifts while loading). They are a confirmed Google ranking factor.

What's the difference between field data and lab data?

Field data comes from real Chrome users who visited the page (Google's CrUX dataset) and reflects actual experience. Lab data comes from a single simulated Lighthouse test run. Field data is more representative but only exists for pages with enough real traffic; this tool uses field data when available and falls back to lab data otherwise.

Why is my INP score missing?

INP requires a real user interacting with the page, so it can only come from field data (CrUX). If a page doesn't have enough real-world traffic for Google to have field data, INP will show as unavailable rather than being estimated from a lab test.
