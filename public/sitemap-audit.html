What this actually does (read before you rely on it)
This fetches your sitemap.xml, extracts every <loc> URL, and runs each one through the same technical checks as the Indexability Checker: HTTP status, robots.txt rules, meta robots "noindex", the X-Robots-Tag header, and canonical tag mismatches. It does not tell you whether a page is already indexed — only whether it's technically eligible to be. Sitemaps larger than 200 URLs are sampled from the first 200 entries to keep the scan fast.

Frequently asked questions

What is sitemap waste?

Sitemap waste refers to URLs listed in a sitemap.xml that can never actually be indexed — because they're blocked by robots.txt, carry a noindex tag, or have a canonical tag pointing elsewhere. Submitting these URLs to search engines or spending crawl budget on them accomplishes nothing.

Why would my sitemap contain pages that can't be indexed?

This commonly happens after a site migration, a CMS plugin auto-generating the sitemap without checking robots directives, or noindex tags being added to pages without removing them from the sitemap afterward.

How many URLs can be audited at once?

Up to 200 URLs per sitemap are checked in a single audit to keep the tool fast and free. Larger sitemaps are sampled from the first 200 entries.

Is this tool free?

Yes, the Sitemap Waste Auditor is free to use with no API key, account, or daily limit.
