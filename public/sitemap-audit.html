What this actually does (read before you rely on it)
This fetches your sitemap.xml, extracts every <loc> URL, and checks each one for: HTTP status, robots.txt rules, meta robots "noindex", the X-Robots-Tag header, canonical tag mismatches, and whether the URL redirects elsewhere. URLs are checked in parallel (up to 15 at a time), so total time depends on how many URLs there are and how fast the target server responds — the live estimate updates continuously based on the actual speed observed so far, it isn't a fixed guess. This does not tell you whether a page is already indexed, only whether it's technically eligible to be.

What gets checked, and why it matters

SignalWhat it meansIf it blocks indexing
HTTP status code Whether the page loads successfully (200) or returns an error. A 4xx or 5xx status means there's no valid page to index.
Redirect chain Whether the sitemap URL actually resolves to a different final URL. Search engines usually index the destination instead — the sitemap entry is redundant.
robots.txt A file at your site's root that tells crawlers which paths they may visit. A Disallow rule matching the page's path stops crawlers from fetching it.
Meta robots / X-Robots-Tag A noindex directive, either in the page's HTML or its HTTP headers. Explicitly tells search engines to exclude the page from the index.
Canonical tag Declares which URL is the "main" version of a page. If it points elsewhere, search engines usually index that URL instead.

Frequently asked questions

What is sitemap waste?

Sitemap waste refers to URLs listed in a sitemap.xml that can never actually be indexed — because they're blocked by robots.txt, carry a noindex tag, redirect elsewhere, or have a canonical tag pointing to a different URL.

Why does a redirect count as sitemap waste?

A sitemap should only list the final, canonical URLs you want indexed. If a listed URL redirects somewhere else, search engines will typically index the destination instead, making the original entry redundant and a sign the sitemap needs cleanup.

How many URLs can be audited at once?

Up to 10,000 URLs per sitemap can be audited in a single run. URLs are checked in parallel with live progress and a time estimate shown throughout.

How long does a large audit take?

It depends on how many URLs are in the sitemap and how fast the target server responds. The tool shows a live, continuously updated time estimate based on the actual speed of the checks completed so far, rather than a fixed guess.
