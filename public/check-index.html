What this actually does (read before you rely on it)
This does not tell you whether Google has already indexed the page (that would require the Search Console API, which needs domain ownership). Instead, it tells you whether the page is technically eligible to be indexed right now — which is usually the more actionable question. It checks: robots.txt rules, a <meta name="robots"> tag with "noindex", an X-Robots-Tag HTTP header with "noindex", the page's HTTP status code, and whether its canonical tag points somewhere else. If any of these block indexing, Google won't index the page no matter how many times you submit it.
