What this actually does (read before you rely on it)
Each URL is sent to a site: search query via the Google Custom Search API on the server. A URL is marked Indexed if Google returns at least one result for that exact page, and Not indexed if it returns zero. This reflects Google's index only — it does not check Bing, Yandex, or DuckDuckGo, and it does not submit or request indexing on your behalf. The free tier allows 100 lookups/day; if you go over quota, remaining URLs will show as an error rather than a result.
