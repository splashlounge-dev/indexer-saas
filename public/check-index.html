What this actually does (read before you rely on it)
This does not tell you whether Google has already indexed the page (that would require the Search Console API, which needs domain ownership). Instead, it tells you whether the page is technically eligible to be indexed right now — which is usually the more actionable question. If any of these block indexing, Google won't index the page no matter how many times you submit it.

Why pages don't get indexed

Blocked by robots.txt

If a Disallow rule in your robots.txt file matches the page's path, Google's crawler won't fetch the page at all — so it can't be indexed, regardless of anything else on the page.

Noindex tag

A <meta name="robots" content="noindex"> tag in the page's HTML, or an equivalent X-Robots-Tag: noindex HTTP header, tells Google directly to leave the page out of search results.

Canonical pointing elsewhere

If the page's canonical tag names a different URL, Google treats that other URL as the "real" version and typically indexes it instead of the one you're checking.

Non-200 response

Redirects, 404s, and server errors all prevent indexing of the original URL. A redirect isn't necessarily a problem — but it means the destination URL is what gets indexed, not the one you submitted.

Frequently asked questions

Does this tool tell me if Google has already indexed my page?

No. Confirming that a page is already sitting in Google's index requires the Search Console API, which only works for domains you own and verify. This tool checks whether a page is technically eligible to be indexed right now — which is the part you can actually fix.

Why isn't my page getting indexed by Google?

The most common reasons are a noindex tag in the page's meta robots or X-Robots-Tag header, a robots.txt rule blocking the URL, a canonical tag pointing to a different page, or the page returning a non-200 HTTP status. This tool checks all four automatically.

Is this indexability checker free?

Yes. There's no API key, no account, and no daily limit on how many URLs you can check.
