What this actually does (read before you rely on it)
  • Covers: Bing, Yandex, DuckDuckGo — all support IndexNow natively.
  • Does not cover Google. Google has no public instant-index API for ordinary pages. Keep submitting your sitemap in Search Console and build normal internal links — that's still what drives Google indexing.
  • "Accepted" ≠ "indexed." A 200/202 response means the engine received the notification, not that the page is in the index yet. Indexing still depends on the page's own quality and crawlability.
  • No key file to upload — this tool hosts the IndexNow key for you automatically.
